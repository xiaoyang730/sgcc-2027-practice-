# 2027国网公共与行业知识刷题

移动端优先的静态刷题网站，包含832道公共与行业知识题。

## 功能

- 背题模式、分类刷题和随机刷题
- 六类题目：单选、多选两选、多选三选、多选全选、判断对、判断错
- 每题正确/错误次数、正确率和重点复习统计
- 学习记录保存在当前浏览器，可导出和导入

## GitHub Pages

推送到 `main` 分支后，由 `.github/workflows/deploy-pages.yml` 自动发布。
